During my 4-week experience at **1337 School (42 Network)**, I explored the foundations of computer science through a series of intense, project-based modules.  
Each day was filled with problem-solving, debugging, peer learning, and late-night coding sessions — all contributing to huge personal and technical growth.

## 💻 C Projects Summary

| Module | Focus | Key Concepts |
|:-------:|:------|:-------------|
| **C00** | Basics | print functions, loops, and simple syntax |
| **C01** | Memory & Variables | pointers, arrays, function arguments |
| **C02** | String Manipulation | `strcpy`, `strcmp`, custom functions |
| **C03** | Advanced Strings | prefix/suffix comparisons, concatenation |
| **C04** | Math & Conversion | recursion, number conversions |
| **C05** | Recursion | factorial, power, Fibonacci, primes |
| **C06** | Command-line Args | parsing, program arguments |
| **C07** | Memory Allocation | `malloc`, `free`, deep copy |
| **C08** | Header Files | structs, typedefs, organization |
